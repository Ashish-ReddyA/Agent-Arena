# Hybrid Research Arcade implementation

Approved intent: continue the shared Hyperagent implementation request, preserving Research Arcade and adding local/website execution. Billing and paid infrastructure provisioning are excluded.

## Design and scope
Keep the charcoal illustrated catalog and the same six identities through configure/run/results. A shared deterministic JavaScript engine defines six bounded experiments: Game Forge constructs a playable maze blueprint; Repair Bay repairs an invalid maze; Game Runner navigates a seeded hidden maze; Escape Room combines private clues; Tiny Civilization allocates scarce resources; Relay Studio passes a blueprint between agents. Rule Change is a scheduled engine intervention, recorded with its exact step. These first versions do not execute arbitrary source code. Existing Docker tools remain available under an explicitly advanced legacy route.

The hosted Node process executes only trusted engine code and makes bounded model requests. Generated JSON is validated; no eval, shell, generated scripts or unsandboxed HTML. Browser preview uses a trusted React maze renderer. Local execution uses the same engine and runner in a loopback Node service, with BYOK or local Ollama. Existing Docker bridge is preserved for unrestricted local workspace experiments.

SQLite on an operator-supplied persistent disk stores password hashes, hashed session tokens, owner-scoped run manifests, events and snapshots. Hosted runs require sign-in. API keys live in process memory only. No secrets in run records. Server restart interrupts in-flight runs explicitly. Per-run step, output-token and time limits, per-account concurrency and storage caps protect resources. Hosted providers use a fixed HTTPS allowlist. Local service requires an origin allowlist and authentication.

## Shared engine contract
`lab/engine.mjs` exports `CATALOG`, `createExperiment(config)`, `observe(state, slot)`, `applyAction(state, slot, action)`, `intervene(state)`. Pure serializable state, functions return next state (observe returns model-safe observation). CATALOG entries: `{id,title,category,summary,description,minAgents,maxAgents,accent,objective,actions}`. State fields: `{arenaId,seed,step,status,agents,events,checks,metrics,artifact,...}`; status running/completed. events array of `{step,agent,text,kind}`; checks array `{name,passed,detail}`; metrics numeric map. Artifact for maze is `{kind:'maze',title,grid:string[],start:[x,y],goal:[x,y]}`. `createExperiment` accepts `{arenaId,agentCount,seed,objective,maxSteps,ruleChangeStep}`; engine rejects invalid raw inputs. observe provides allowed action schema and only slot-visible information. Engine increments state.step on every attempted action; runner terminates on maxSteps even if engine remains running.

## HTTP contract
`server/lab-handler.mjs` exports `handleLabRequest(Request): Promise<Response>`. Mounted at `/api/lab/[...path]` for Node and `/api/lab/*` in the loopback server (43822). JSON errors `{error}`. Bearer sessions, token returned only at login/register, stored by UI in sessionStorage per runtime. `GET health` => `{ok,execution,storage}`. `POST auth/register|login` `{username,password}` => `{token,user:{id,username}}`; `POST auth/logout`; `GET auth/me` => `{user}`. `GET runs` => `{runs}`. `POST runs` body `{config:{arenaId,agentCount,seed,objective,maxSteps,ruleChangeStep},provider:{id,model,apiKey},execution:'hosted'|'local'}` => `{run}`. Allowed provider ids openrouter/nvidia, plus ollama only local at fixed localhost URL. `GET runs/:id` => `{run}`; `POST runs/:id/stop` => `{run}`; `DELETE runs/:id` only inactive owned records. Run shape `{id,ownerId,execution,status,config,state,usage:{inputTokens,outputTokens,calls},createdAt,updatedAt,error?}`. Runner rotates agent-1..n, supplies observe, validates JSON model action, records failures, caps time/output, aborts stop, persists after each transition. No fake/demo results in saved model runs.
